# Exercicio 01 - LPII 2026.2

Atividade da faculdade organizada por questoes.

## Estrutura

```text
Manoel-Lourran/
├── Questao01/
└── Questao02/
```

## Conteudo

- `Questao01`: funcionarios, gerente, analista, heranca e polimorfismo.
- `Questao02`: animais, cachorro, gato, heranca e polimorfismo.

## Como rodar

Entre na pasta `Manoel-Lourran` e compile uma questao por vez:

```powershell
javac Questao01/*.java
java Questao01.Main
```

```powershell
javac Questao02/*.java
java Questao02.Main
```
