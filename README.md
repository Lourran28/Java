## Sobre o repositório

Este repositório reúne minhas atividades, exercícios e pequenos projetos de estudo em Java. A proposta é praticar com frequência, registrar a evolução e construir uma base sólida na linguagem.

Cada atividade possui código organizado, explicação do problema, conceitos utilizados e exemplos de execução.

## Como praticar em casa

Os enunciados e as explicações estão na pasta [instrucoes](./instrucoes). Leia a aula, tente resolver por conta própria e só depois compare com a solução em `atividades/`.

## Organização

```text
atividades/
└── 001-nome-da-atividade/
    ├── TreinoJava.java
    └── README.md
```

- `TreinoJava.java`: solução da atividade
- `README.md`: enunciado, explicação e exemplos
- Pastas numeradas para manter a ordem de evolução

## Trilha de estudos

- Fundamentos da linguagem e entrada de dados
- Operadores, condicionais e estruturas de repetição
- Métodos, arrays e manipulação de strings
- Programação orientada a objetos
- Coleções, exceções e arquivos
- Integração com bancos de dados
- Pequenos projetos para consolidar o aprendizado
