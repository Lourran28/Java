# Atividade 01 - Variaveis e textos

## Objetivo

Treinar:

1. Criar variaveis.
2. Mostrar mensagens com `System.out.println`.
3. Juntar texto e variaveis usando `+`.

## Arquivo

O codigo esta no arquivo:

```text
TreinoJava.java
```

## Como rodar

Dentro desta pasta, use:

```powershell
javac TreinoJava.java
java TreinoJava
```

## Saida

```text
Meu nome e manoel
Minha idade e 19
MInha cidade e petrolandia
Meu nome e manoel Minha idade e 19 moro em petrolandia
```
