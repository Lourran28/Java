# Atividade 04 - Scanner

## Objetivo

Treinar entrada de dados com `Scanner`.

## Arquivo

```text
TreinoJava.java
```

## Como rodar

Dentro desta pasta, use:

```powershell
javac TreinoJava.java
java TreinoJava
```

Depois digite uma idade e aperte Enter.

## Testes feitos

```text
17 -> Menor de idade
18 -> Maior de idade
25 -> Maior de idade
```
