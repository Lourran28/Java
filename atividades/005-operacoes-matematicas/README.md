# Atividade 05 - Operacoes matematicas

## Objetivo

Treinar contas simples com dois numeros digitados no terminal.

## Arquivo

```text
TreinoJava.java
```

## Como rodar

Dentro desta pasta, use:

```powershell
javac TreinoJava.java
java TreinoJava
```

Depois digite dois numeros e aperte Enter depois de cada um.

## Teste feito

```text
10
5
```

Resultado:

```text
Soma: 15
Subtracao: 5
Multiplicacao: 50
```
