# Atividade 06 - Double e media

## Objetivo

Treinar numeros decimais com `double`, leitura com `Scanner`, calculo de media e decisao com `if` e `else`.

## Arquivo

```text
TreinoJava.java
```

## Como rodar

Dentro desta pasta, use:

```powershell
javac TreinoJava.java
java TreinoJava
```

Depois digite duas notas e aperte Enter depois de cada uma.

## Teste feito

```text
6
6
```

Resultado:

```text
Reprovado
Sua media final foi 6.0
```

## Conceitos usados

- `double`
- `Scanner`
- `nextDouble()`
- media aritmetica
- `if` e `else`
