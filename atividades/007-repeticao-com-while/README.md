# Atividade 07 - Repeticao com while

## Objetivo

Usar `while` para repetir um bloco de codigo enquanto uma condicao for verdadeira.

## Arquivo

```text
TreinoJava.java
```

## Como rodar

Dentro desta pasta, use:

```powershell
javac TreinoJava.java
java TreinoJava
```

## Saida

```text
1
2
3
4
5
```

## Conceitos usados

- `while`
- contador
- condicao `<=`
- incremento com `++`
