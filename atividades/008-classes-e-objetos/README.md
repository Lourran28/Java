# Atividade 08 - Classes e objetos

## Objetivo

Criar uma classe `Pessoa`, criar um objeto a partir dela e preencher seus atributos.

## Arquivos

```text
Main.java
Pessoa.java
```

## Como rodar

Dentro desta pasta, use:

```powershell
javac Main.java Pessoa.java
java Main
```

## Saida

```text
Ana
20
```

## Conceitos usados

- classe
- objeto
- atributos
- `new`
- acesso a atributos com `.`
