# Atividade 09 - Metodos em uma classe

## Objetivo

Criar um metodo na classe `Pessoa` e chamar esse metodo por meio de um objeto.

## Arquivos

```text
Main.java
Pessoa.java
```

## Como rodar

Dentro desta pasta, use:

```powershell
javac Main.java Pessoa.java
java Main
```

## Saida

```text
Ola, eu sou gih e tenho 18 anos.
```

## Conceitos usados

- classe
- objeto
- atributos
- metodo
- `public void`
- chamada de metodo com `.`
