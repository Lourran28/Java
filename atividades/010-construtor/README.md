# Atividade 10 - Construtor

## Objetivo

Usar um construtor para criar uma pessoa ja com nome e idade.

## Arquivos

```text
Main.java
Pessoa.java
```

## Como rodar

Dentro desta pasta, use:

```powershell
javac Main.java Pessoa.java
java Main
```

## Saida

```text
Ola, eu sou gih e tenho 20 anos.
```

## Conceitos usados

- construtor
- `this`
- classe
- objeto
- atributos
- metodo
