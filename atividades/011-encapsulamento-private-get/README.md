# Atividade 11 - Encapsulamento com private e get

## Objetivo

Proteger os atributos da classe `Pessoa` usando `private` e acessar os dados com metodos get.

## Arquivos

```text
Main.java
Pessoa.java
```

## Como rodar

Dentro desta pasta, use:

```powershell
javac Main.java Pessoa.java
java Main
```

## Saida

```text
Meu nome: ana
Minha idade: 20
```

## Conceitos usados

- encapsulamento
- `private`
- construtor
- `this`
- `getNome()`
- `getIdade()`
