# Atividade 12 - Setter para alterar idade

## Objetivo

Usar um setter para alterar um atributo protegido por `private`.

## Arquivos

```text
Main.java
Pessoa.java
```

## Como rodar

Dentro desta pasta, use:

```powershell
javac Main.java Pessoa.java
java Main
```

## Saida

```text
Idade antes: 20
Idade depois: 21
```

## Conceitos usados

- encapsulamento
- `private`
- getters
- setter `setIdade()`
- construtor
- `this`
