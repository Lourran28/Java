# Atividade 13 - Validar idade no setter

## Objetivo

Usar `if` dentro de `setIdade()` para impedir que uma idade negativa seja salva.

## Arquivos

```text
Main.java
Pessoa.java
```

## Como rodar

Dentro desta pasta, use:

```powershell
javac Main.java Pessoa.java
java Main
```

## Saida

```text
Idade invalida
Idade depois da tentativa: 20
Idade atualizada: 21
```

## Conceitos usados

- encapsulamento
- `private`
- getter
- setter
- `if` e `else`
- validacao de dados
