# Atividade 14 - Dois objetos da mesma classe

## Objetivo

Criar dois objetos diferentes usando a mesma classe `Pessoa`.

## Arquivos

```text
Main.java
Pessoa.java
```

## Como rodar

Dentro desta pasta, use:

```powershell
javac Main.java Pessoa.java
java Main
```

## Saida

```text
Pessoa 1: Ana - 20 anos
Pessoa 2: Bia - 18 anos
```

## Conceitos usados

- classe
- objeto
- construtor
- atributos privados
- getters
- dois objetos da mesma classe
