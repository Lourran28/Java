# Atividade 15 - Primeira heranca

## Objetivo

Criar uma classe `Cachorro` herdando atributos e metodos da classe `Animal`.

## Arquivos

```text
Main.java
Animal.java
Cachorro.java
```

## Como rodar

Dentro desta pasta, use:

```powershell
javac Main.java Animal.java Cachorro.java
java Main
```

## Saida

```text
Animal: Rex
Idade do animal: 3
Rex latiu
```

## Conceitos usados

- heranca
- `extends`
- `super`
- atributos `protected`
- metodo herdado
