# Instrucoes das aulas

Esta pasta contem o enunciado e as explicacoes de cada atividade do repositorio.

Para praticar em casa:

1. Abra a instrucao da aula que deseja fazer.
2. Leia o objetivo e as regras.
3. Tente resolver sem olhar a solucao em `atividades/`.
4. Compile e execute o codigo pelo terminal.
