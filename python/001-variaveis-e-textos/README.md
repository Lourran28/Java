# Atividade 01 - Variaveis e textos

## Objetivo

Criar variaveis em Python e mostrar uma frase no terminal.

## Desafio

No arquivo `main.py`:

1. Crie uma variavel para seu nome.
2. Crie uma variavel para sua idade.
3. Mostre uma frase juntando os dois valores.

Exemplo de saida:

```text
Meu nome e Ana e tenho 20 anos.
```

## Como rodar

Dentro desta pasta, use:

```powershell
python main.py
```
