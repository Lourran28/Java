# Atividade 01 - Variaveis e textos

## Objetivo

Treinar:

1. Criar variaveis.
2. Mostrar mensagens com `print`.
3. Juntar texto e variaveis em uma frase.

## Arquivo

Escreva sua tentativa no arquivo:

```text
main.py
```

Leia primeiro as instrucoes em `python/instrucoes/Aula01_Instrucoes.md`.

## Saida esperada

Use seus proprios dados. Exemplo:

```text
Meu nome e Lourran
Eu tenho 20 anos
Eu moro em Petrolandia
Meu nome e Lourran, tenho 20 anos e moro em Petrolandia
```

## Como rodar

Dentro desta pasta, use:

```powershell
python main.py
```
