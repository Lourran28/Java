# Atividade 002 - Entrada de dados

## Tema

Entrada de dados com `input`, conversao com `int` e frase com `f-string`.

## Enunciado

Crie um programa que pergunte:

1. Nome.
2. Idade.
3. Cidade.

Depois mostre uma frase final usando essas informacoes.

## Arquivo

Escreva sua tentativa no arquivo `main.py`.
